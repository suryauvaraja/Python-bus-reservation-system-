# 🚌 Python Bus Reservation System

The **Bus Reservation System** is a console-based Python application developed to manage bus bookings and passenger reservations. The project demonstrates Python fundamentals, functions, conditional statements, loops, lists, and basic classes and objects.

## 🚀 Features

* 🚌 View available buses
* 👤 Enter passenger details
* 🎫 Book bus tickets
* 💺 Select seats
* 📋 View booking details
* ❌ Cancel bookings
* 🔄 Check seat availability
* 🚪 Exit the application

## 🛠️ Technologies Used

* Python 3
* Classes and Objects
* Functions
* Conditional Statements
* Loops
* Lists
* User Input

## 💻 Application Workflow

### 1. View Available Buses

The user can view the buses available for reservation.

### 2. Enter Passenger Details

The system collects basic passenger information required for the booking.

### 3. Seat Reservation

The user can select an available seat and complete the reservation.

### 4. View Reservation

The system displays the passenger's booking details.

### 5. Cancel Reservation

Users can cancel their existing reservation.

### 6. Check Seat Availability

The system keeps track of available and reserved seats.

## 🎯 Project Objective

The objective of this project is to build a simple bus reservation application using Python and understand how programming concepts can be applied to a real-world reservation system.
